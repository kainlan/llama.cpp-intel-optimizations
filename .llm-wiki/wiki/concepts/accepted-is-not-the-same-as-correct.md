# Accepted is not the same as correct

A primitive being accepted by oneDNN (no refusal in the log) does not guarantee correct numerics — the 3-D WOQ scale mask is accepted yet reproducibly wrong on B70; the same trap as ext_oneapi_enable_peer_access.
