# Kernel confirmation from output, not setup

Because the fast-path can bypass setup preconditions, the actually-running kernel must be verified from GGML_SYCL_MUL_MAT_ROUTE_TRACE=1 or an oracle-fit ratio — a passing precondition is not evidence about which kernel ran.
