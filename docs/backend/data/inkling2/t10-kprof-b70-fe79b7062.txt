  sycl.binbcast.event marker submissions (one per bin-broadcast op in the default event mode), 2034 are the

  (177 us / 8 = 22.1 us). The prompt path is the decode mat-vec applied per pair; tokens that select the same expert

  submissions (288 per token; src/models/inkling2.cpp graph::mix and the relative-bias table), 445 ms of device
