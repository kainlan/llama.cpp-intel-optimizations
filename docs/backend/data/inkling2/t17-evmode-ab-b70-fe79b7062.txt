Reading. The host load varied between arms (the implementers' builds started and stopped), and an ABBA order does not
protect against that. pp512 does not depend on the marker count, so it is used as the covariate: the arms pair as
(r, d2) at pp ~41-43 and (r2, d) at pp ~31-32. In each pair reuse is faster in tg: 4.99 against 4.04 (+24%) and
4.14 against 2.95 (+40%). With the profile pair (-14% per token) that is three comparisons in one direction. The
size is not established: a clean ABBA with no builder running is owed before any figure is quoted as the gain.
Also seen: a concurrent build takes Inkling decode from ~4.0-4.3 to ~3.0 t/s, as expected for a host-bound decode.
